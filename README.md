# KIMSTAR

Corporate static website for **KIMSTAR**, developed by **Austin Kimathi** (Admission No. **169649**) for the Mini-Project Git Workflow Challenge.

## Description

KIMSTAR is a professional technology consulting website. It presents the firm’s positioning, services, selected project work, FAQs, and a validated contact enquiry form. The site is a functional static system (HTML/CSS/JavaScript) designed for GitHub Pages deployment.

## Features

- Responsive navigation with animated mobile menu
- Homepage hero, services overview, and project previews
- About page with mission/vision and FAQ accordion
- Services catalogue
- Projects portfolio with category filtering
- Contact form with client-side validation and feedback
- Professional design system and responsive layout

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)
- Git / GitHub
- GitHub Pages

## Git Workflow

This project was delivered using a professional GitHub workflow:

- Agile planning with milestones, issues, and a Kanban board
- Feature branches named `feat|fix|style/[issue]-[description]`
- Conventional Commits (`feat`, `fix`, `style`, `docs`, `chore`, `refactor`)
- Pull requests into protected `main` (no direct development commits)
- Engineered merge conflicts with evidence under `/evidence/`
